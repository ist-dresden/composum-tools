Package Manager

Browses, inspects and manages FileVault content packages. Pick a package version in the tree on the left to see its details and actions; pick a group or name folder instead to see every package version nested under it, with a Purge Old Versions action that deletes all but the latest version of each package found there.

Two backends, switched with the mode toggle above the tree (a full page reload - there is no live in-place switch):

  • JCR mode (default) - the classic, single-source package store under /etc/packages. Full lifecycle: Create, Upload, Edit, Filters, Install, Uninstall, Build, Coverage, Download, Delete.
  • Registry mode - every bound FileVault PackageRegistry service, merged into one tree. Read-only management: Install, Uninstall, Download, Delete - no Create, Upload, Edit, Filters or Build.

Install, Uninstall and Build run synchronously on the request - there is no async job queue and no persisted install history; each operation's log is shown once, in the result popup of the request that triggered it.
